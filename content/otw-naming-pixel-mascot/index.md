Claude Code나 Codex를 쓰다 보면 같은 말을 여러 번 하게 된다. 그래서 내가 했던 지적을 저장했다가 비슷한 요청이 나올 때 다시 보여 주는 플러그인을 만들었다. 지금 이름은 [Off the Wall](https://github.com/toranalytics/off-the-wall)이다.

그런데 이름만 보면 이 도구가 뭘 하는지 바로 떠오르지 않는다. README의 앵무새도 그냥 말을 따라 하는 도구처럼 보일 수 있다. 실제로 만들고 싶었던 건 내가 앞서 한 말을 AI에게 다시 떠올려 주는 쪽이었다.

## 화나는 기분을 이름에 넣어 봤다

같은 실수를 보고 있으면 “내가 아까 말했잖아”라는 말이 나온다. 이 기분을 좀 더 짧고 장난스럽게 표현하고 싶었다. `FFS Again` 같은 이름도 생각해 봤다. 답답함은 전해지지만, 이름만으로는 AI 코딩 도구에서 어떤 문제를 다루는지 알기 어려웠다.

그래서 `dude-toldya`라는 이름을 후보로 올렸다. “야, 내가 말했잖아”에 가까운 구어체다. 도구를 켜 놓고 계속 AI를 혼내는 이미지보다는, 전에 했던 말을 다시 보여 주는 친구 같은 느낌을 원했다.

## 비슷한 이름이 이미 있었다

찾아보니 [toldya](https://www.npmjs.com/package/toldya)라는 도구가 이미 있었다. Claude Code 기록에서 반복된 지적을 찾고, 사용자가 고른 내용을 규칙 파일에 반영하는 도구다. 비슷한 문제를 다루는 만큼 `dude-toldya`가 이름만 살짝 바꾼 것처럼 보일 수 있다.

내 플러그인은 지적을 규칙으로 바꾸는 대신 내가 쓴 표현을 그대로 보관하고 다시 보여 주는 쪽을 택했다. 그래도 이름이 주는 혼동은 별개의 문제다. 정확한 이름, 패키지명, 상표를 모두 검토한 것은 아니라서 아직 이름을 바꾸지는 않았다.

## 앵무새 대신 AI를 그려 봤다

캐릭터도 바꿔 보고 싶었다. 처음에는 구겨진 메모지에 표정을 넣었다. 과거의 지적을 보관하는 역할은 보여 주지만, Claude Code나 Codex를 쓰다가 답답해진 상황이 바로 떠오르지는 않았다.

그다음에는 [Gajae Code의 GitHub](https://github.com/Yeachan-Heo/gajae-code)에 있는 도트 캐릭터와 어두운 배경 구성을 참고했다. 가재나 로고를 가져오지는 않고, 픽셀 표현과 작은 캐릭터가 주는 인상을 참고했다.

여기에 [‘조용히 하세요!’ 짤](https://namu.wiki/w/조용히%20하세요!)의 허탈한 타이밍을 섞어 봤다. 멍한 터미널 로봇이 가벼운 꿀밤을 맞는 장면이다. AI 이미지 생성 도구로 만든 시안이고, 아직 확정된 마스코트는 아니다.

## 이름보다 먼저 설명해야 할 것

이 도구는 Claude Code와 Codex에서 같은 작업 폴더에 저장된 과거 지적을 골라 답변 전에 원문으로 보여 준다. 다만 골라진 문장이 항상 관련 있다는 보장은 없다. 무관한 지적이 함께 붙는 문제도 확인했고, 실제 사용자가 덜 반복해서 지적하는지는 아직 측정하지 못했다.

이름과 그림이 재미있어도 그 한계는 그대로 적어야 한다. 우선은 후보 이름과 시안을 살펴보고, 기존 도구와 혼동되지 않으면서도 무엇을 하는지 더 잘 전할 수 있는지 고민해 보려고 한다.
