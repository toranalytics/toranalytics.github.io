와이낫에서 마케팅 업무를 하면서 광고 결과를 정리해 전달했다. 숫자를 모으는 것도 일이었지만, 그 숫자를 보는 사람이 현재 상황을 이해할 수 있도록 설명을 붙이는 데도 시간이 들었다.

나는 반복되는 리포트 작업을 줄이고 싶었다. 처음부터 큰 대시보드를 생각한 건 아니었다. 매번 비슷하게 정리하던 스프레드시트 작업에서 출발했다.

## 처음에는 시트 안에서 해결했다

시트에서 반복하는 작업을 자동화했다. 매번 직접 처리하던 내용을 일정한 방식으로 정리하려는 시도였다.

그런데 시트 구조가 바뀌면 기존 방식도 영향을 받았다. 데이터가 늘어나고 보여 줘야 할 내용이 달라질수록 시트 안에서 모든 걸 해결하기 어려워졌다.

## 화면을 따로 만들었다

이후 데이터를 불러와 지표와 흐름을 볼 수 있는 대시보드로 넓혔다. 결과를 정리하는 화면과 리포트를 전달하는 방식도 함께 고민했다. AI가 만든 분석 문구는 사람이 다시 살펴보고 수정할 수 있도록 했다.

내 역할은 어떤 데이터를 어떤 흐름으로 보여 줄지 정하고 결과를 확인하는 것이었다. 구현에는 AI 코딩 도구를 활용했다. 화면과 기능을 만들었다는 것과 실제로 누군가의 판단이 좋아졌다는 것은 다르다. 후자는 이 글에서 단정하지 않겠다.

## 남은 한계도 있었다

외부 데이터를 연결할 때는 인증이나 접근 조건을 확인해야 했고, 원하는 모든 내용을 항상 자동으로 가져올 수 있었던 것도 아니다. 대시보드를 만들었다고 리포트 업무의 모든 문제가 사라지지는 않았다.

이때부터 계속 생각한 질문이 있다. 숫자를 잘 아는 내가 화면을 이해하는 것과, 처음 보는 사람이 같은 화면에서 다음 행동을 정하는 것은 다르지 않을까. 이후 다른 환경에서 도구를 만들 때도 이 질문을 다시 꺼내게 됐다.
