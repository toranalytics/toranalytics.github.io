> 写完这篇文章后，我把名字定为 Dude Toldya。仓库名改成了 `dude-toldya`，命令改成了 `duto`。

用 Claude Code 或 Codex 时，总会把同一句话说好几遍。所以我做了一个插件：把我以前做过的纠正保存下来，遇到类似请求时再原样显示出来。它现在的名字是 [Off the Wall](https://github.com/toranalytics/off-the-wall)。

但光看名字，很难马上想到这个工具是做什么的。README 里的鹦鹉看上去也像只会学舌的工具。我真正想做的，是让 AI 重新想起我之前说过的话。

## 把恼火的心情放进名字里

看着同样的错误，嘴里就会冒出“我刚才不是说过了吗”。我想用更短、更带点玩笑的方式表达这种心情，也想过 `FFS Again` 这样的名字。烦躁感能传达出来，但单看名字，看不出它在 AI 编码工具里解决的是什么问题。

于是我把 `dude-toldya` 列为候选名字。它接近口语里的“喂，我跟你说过了”。比起一个一直开着、不停责骂 AI 的形象，我更想要一种朋友般的感觉：把你之前说过的话再给你看一遍。

## 已经有类似的名字了

查了一下，已经有一个叫 [toldya](https://www.npmjs.com/package/toldya) 的工具。它会从 Claude Code 的记录里找出反复出现的纠正，把用户选中的内容写进规则文件。因为处理的是相似的问题，`dude-toldya` 可能看起来像是把名字稍微改了一下。

我的插件没有把纠正变成规则，而是选择把我写下的原话保存下来，再原样显示。但名字带来的混淆是另一回事。我没有把准确的名称、包名和商标全部查过，所以当时还没有改名。

## 用 AI 代替鹦鹉来画

我也想换掉角色。一开始，我给一张皱巴巴的便签纸加上了表情。它能表现出保存过去纠正的作用，但看不出使用 Claude Code 或 Codex 时那种被气到的情境。

后来我参考了 [Gajae Code 的 GitHub](https://github.com/Yeachan-Heo/gajae-code) 上的点阵角色和深色背景的构图。我没有拿龙虾或徽标，只是参考了像素表现和小角色带来的印象。

再把[“请安静！”梗图](https://namu.wiki/w/조용히%20하세요!)那种哭笑不得的时机感混进去：一个发呆的终端机器人被轻轻敲了一下脑袋。这是用 AI 图像生成工具做的草图，还不是确定的吉祥物。

![一个像素风 AI 机器人被轻轻敲了一下脑袋，仿佛在提醒它想起过去的纠正](/img/dude-toldya-ai-mascot.png)

## 比名字更该先说明的事

这个工具会在 Claude Code 和 Codex 里，从同一个工作文件夹中挑出保存的过去纠正，在回答之前原文显示。但不能保证被挑出的句子总是相关。我也确认过，会有不相关的纠正一起附上来，而真实用户是否因此减少了重复纠正，我还没有测量过。

名字和图画再有趣，这些局限也要照实写下来。目前我先看看候选名字和草图，再想想怎样既不与现有工具混淆，又能更好地说明它做什么。
