다음 세션이 되면 처음부터 다시입니다. 그래서 **내가 했던 지적을 내 말 그대로 다음 답 앞에 놓아 주는 도구**를
만들었습니다. 이름은 [Off the Wall](https://github.com/toranalytics/off-the-wall)입니다.

## 왜 요약이 아니라 인용인가

지적을 기억시키는 흔한 방법은 규칙 파일입니다. 지적을 모아 "항상 테스트를 실행할 것" 같은 한 줄 규칙으로
요약해 두는 거죠. 저도 그렇게 해 왔는데, 정말 효과가 있는지 재 보기로 했습니다.

실제로 바로 뒤에 지적이 나왔던 요청 39개를 골라 조건마다 다시 답하게 했습니다. 답은 Opus 5.5가 했고, 채점은
Sonnet이 어느 조건의 답인지 모르는 상태에서 두 답을 비교했습니다. 순서를 바꿔 두 번 물어서 두 번 모두 같은 쪽을
고른 경우만 승리로 셌습니다. 아무것도 붙이지 않은 답과 비교한 결과입니다.

![아무것도 안 붙인 경우 대비 승·무·패](evidence.png)

| 붙인 것 | 승 | 무 | 패 |
| :-- | --: | --: | --: |
| 실제 지적 (상한선) | 36 | 3 | 0 |
| **과거 지적 원문 6개 + 지적 예측 지시** | **25** | **11** | **3** |
| 무작위 한 줄 규칙 3개 | 18 | 15 | 6 |
| 요약한 한 줄 규칙 3개 | 14 | 17 | 8 |

놀랐던 건 마지막 줄입니다. **공들여 요약한 규칙이 아무 규칙이나 붙인 것보다 나을 게 없었습니다.** 반면 내가
했던 말을 그대로 보여 주면 확실히 달라졌습니다. 요약하는 순간 "어떤 상황에서, 얼마나 짜증 났는지"가 사라지는
것 같습니다.

## 어떻게 동작하나

- **매 질문 전**: 저장된 지적 중 이번 요청과 가장 비슷한 3개, 그리고 최근 것을 합쳐 최대 6개를 원문 그대로
  붙입니다. 그리고 "이 사용자가 지금 답에 뭐라고 지적할지 예측하고 피하라"고 지시합니다.
- **매 질문 후**: 직전 답과 새 메시지를 별도 프로세스에서 판정해서, 지적이면 저장합니다. 판정은 이미 쓰고 있는
  `claude`나 `codex` CLI로 돌기 때문에 API 키가 따로 필요 없습니다.
- **처음 설치할 때**: `otw report`가 내 컴퓨터에 이미 있는 기록을 읽어서 내가 무엇을 가장 많이 지적했는지
  보여 줍니다. `--seed`를 붙이면 그 지적들로 바로 인용을 시작합니다.

## 덤: 서브에이전트를 싼 모델로

에이전트가 하위 에이전트를 부를 때 모델을 지정하지 않으면, 검색이나 grep 같은 단순한 일도 가장 비싼 모델로
돌아갑니다. Off the Wall은 하위 에이전트를 부를 때마다 작업에 맞는 모델을 고르게 합니다. 같은 위임 작업 하나를
두 번씩 돌렸더니 $0.17이 들었고, 끈 쪽은 $0.30과 $0.44였습니다. 결과는 같았습니다. 다만 작업 하나를 조건마다
두 번 돌린 것이라 평균이 아니라 참고용 숫자입니다.

![같은 위임의 비용](routing.png)

## 설치

Claude Code:

```
/plugin install off-the-wall --marketplace toranalytics/off-the-wall
```

Codex:

```bash
codex plugin marketplace add toranalytics/off-the-wall
codex plugin add off-the-wall@off-the-wall
```

모든 데이터는 내 컴퓨터의 `~/.otw`에만 남습니다.

## 한계

모든 숫자는 제 한 사람의 기록에서 나왔습니다. 일반 법칙이 아니라 첫 결과입니다. 그래서 여러분의 기록에서도 같은지
궁금합니다. `otw report`를 돌려 보시고 결과를 [이슈](https://github.com/toranalytics/off-the-wall/issues)로
알려 주시면 정말 반갑겠습니다.
